# Hello Cloud

A small site for LinkRidge Cloud. It is an ordinary git repo with a Dockerfile
at the root and an `index.html`.

Use this repository as a GitHub template: **Use this template → Create a new
repository**, then connect *your* copy to a Project.

## Deploy

1. Connect `linkridge-net/hello-cloud` to a Project on your Account.
2. Deploy that Project (owner, admin, or Agent Bearer).

The production URL is `/apps/{project_id}/`. That path serves this `index.html`.

LinkRidge Cloud clones the default branch over HTTPS. Keep this repository
public until private clones are supported.
